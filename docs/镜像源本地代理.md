## 远端离线依赖更新

`gpu-server1` 无互联网环境，前端依赖更新采用“本机 npm registry 转发器 + SSH 反向端口 + 远端 `npm ci`”流程。

### 适用场景

- `package.json` 或 `package-lock.json` 已变更。
- 远端服务器需要更新 `KnowledgeQuiz/node_modules/`。
- 服务器不能直接访问 npm registry。

### 1. 本机启动 npm registry 转发器

在前端目录运行：

```powershell
python scripts/npm-registry-proxy.py --listen 127.0.0.1 --port 7890 --registry https://registry.npmmirror.com
```

保持该窗口打开。该脚本会把远端 npm 请求转发到上游 npm registry。

### 2. 本机建立 SSH 反向端口

另开一个本机终端运行：

```powershell
ssh -N -o ExitOnForwardFailure=yes -R 127.0.0.1:7890:127.0.0.1:7890 gpu-server1
```

保持该窗口打开。此时服务器上的 `127.0.0.1:7890` 会转发到本机转发器。

### 3. 服务器验证 registry 连通性

在 `gpu-server1` 上运行：

```bash
curl -I http://127.0.0.1:7890/vue
```

看到 `HTTP/1.1 200 OK` 且 `Server: NpmRegistryProxy/...` 即表示链路正常。

### 4. 服务器按 lockfile 安装依赖

在 `gpu-server1` 上运行：

```bash
cd /home/server/Project/KnowLedgeQuiz/KnowledgeQuiz
npm config set registry http://127.0.0.1:7890
npm config delete proxy || true
npm config delete https-proxy || true
npm ci
```

使用 `npm ci` 而不是 `npm install`，确保远端严格按 `package-lock.json` 安装，不在服务器上改写锁文件。

### 5. 安装后验证

```bash
npm test
npm run build
cd /home/server/Project/KnowLedgeQuiz
bash scripts/test-remote.sh all
```

如果安装过程中出现 `ECONNREFUSED 127.0.0.1:7890`，说明本机转发器或 SSH 反向端口没有保持运行。
